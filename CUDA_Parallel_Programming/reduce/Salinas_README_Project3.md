## Matrix Add Program
- To compile  ```nvcc reduce.cu -o reduce```
- To start program ```./reduce```
- This will prompt a inputs from the user
- If yes you will be prompted width and height
- else you will be prompted just the length
```
Would you like to input factored length (NxM)? [y/n] 
Input width: <num>
Input height: <Num>

<or>

Input length: <num>

```
